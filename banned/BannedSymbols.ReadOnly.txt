# VTDiag banned APIs: READ-ONLY layer. Owner: Lead.
# Applies to: Contracts, Platform, Collectors, Knowledge, Analysis, Reporting, Monitor.Core, Monitor,
# Testing.Fakes, App (via the Ui layer) and any new project by default. Only VTD.Fixes, VTD.Journal,
# VTD.Session and VTD.Engine may change system state, files or processes.
# Reading files: File.OpenRead / File.ReadAll* / File.ReadLines / Directory.Enumerate*. A shared-read helper for
# files held open by the game (ShooterGame.log) belongs in VTD.Platform as an allowlisted file
# (banned/rs0030-allowlist.txt). User-chosen export destinations are written through the stream a
# SaveFileDialog returns, or by the Engine.
