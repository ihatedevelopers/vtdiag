# VTDiag

**A free, open-source PC check-up for VALORANT players.** Made for [r/ValorantTechSupport](https://www.reddit.com/r/ValorantTechSupport/).

VTDiag scans your PC, compares it with 900+ problems that players have already solved on the subreddit, and tells you in plain language what is most likely wrong and how to fix it.

## Status: v0.1 beta (read-only)

This first release **does not change anything on your PC**. It only reads. What it does:

- **Health check:** the Vanguard requirements (TPM 2.0, Secure Boot, Memory Integrity, virtualization and so on), drivers, network, power settings, and logs.
- **Conflicts:** known conflicting software such as overlays, VPN adapters, Nahimic, Realtek 2.5GbE, other anti-cheats and RGB tools. There are 113 known conflicts.
- **Ranked suspects:** the likely causes in order, with step-by-step guides. Each suspect is labelled honestly: *fixable here*, *manual step*, *ISP*, *Riot or account side*, *likely hardware*, or *unknown*.
- **Report:** a one-click report for Reddit or an AI assistant.
- **Debug bundle:** a `.vtddebug` file you can send to helpers. It lets them understand both your PC problem and any VTDiag bug.

- **Fix it yourself (new in v0.1.1):** every fix VTDiag can propose has plain step-by-step instructions to do it by hand, in English and Turkish. They show under **Do it yourself** on each suspect, and as a list in [docs/MANUAL_FIXES.md](docs/MANUAL_FIXES.md) ([Türkçe](docs/MANUAL_FIXES.tr.md)).

Automatic fixes, each with your consent and fully undoable, come in v0.2 with the installer.

## Download and run

1. Download the latest `VTDiag-…-win-x64.zip` from [Releases](../../releases).
2. Extract it anywhere and run `VTDiag.exe`. Windows 10/11 x64 is required; .NET is not, because it's included.
3. Windows SmartScreen may warn you, because the app isn't code-signed yet. Click **More info → Run anyway**.

## Privacy

- **Stays on your PC:** nothing is uploaded, and there's no telemetry.
- **Redaction:** reports and debug bundles have your username, PC name, serial numbers and Riot tokens removed before you see them. You choose what to share.
- **Vanguard-safe:** VTDiag never touches the game or Vanguard. It loads no drivers, injects nothing and reads no game memory.

## For helpers and moderators

- **Debug bundle:** when a player sends one, it contains the scan, the analysis, the app logs and environment info, all redacted.
- **Plan files:** helpers can write a `.vtdplan` fix plan that the player imports. Every step still needs the player's own click (see `docs/plans.md`).
- **Command line:** the engine has a CLI, `VTDiag.Engine.exe --cli scan --json` / `analyze --json` / `export --debug-bundle <file>`.

## Building

You need the .NET 10 SDK.

```
dotnet build VTDiag.sln -c Release
dotnet test VTDiag.sln
```

The knowledge base lives in `kb/` and is generated by `tools/kb_builder.py` from `data/` and `research/`. See `DESIGN.md` for the architecture and `PROBLEM_CATALOG.md` for the problems it covers.
